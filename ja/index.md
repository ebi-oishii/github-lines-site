# GitHub Lines

このサイトでは、Chrome 拡張機能「GitHub Lines」のプライバシーポリシーとサポート情報を掲載しています。

<div class="notice">
GitHub のファイル一覧に、そのディレクトリの中で各項目が行数の何割を占めるかをバーで表示する拡張です。無料で、広告もアプリ内課金もありません。提供者のサーバーは無く、通信する相手は GitHub だけです。
</div>
